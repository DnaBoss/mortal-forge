# 背景與證據

每個任務及 step 使用最小背景包：目標、目前狀態、可觀察證據與位置、未知、限制、允許動作、完成條件、必要檔案路徑及版本／內容識別碼。

- 交接明列已知、未知、不能假設；上一個 agent 的敘述回到原始檔、命令輸出或實際操作核對。
- 分開當下可見資料、只能事後知道的答案與尚未取得的外部資料；事後答案不得成為當下決策依據。
- 傳已核對的證據與必要差異，不傳整個 repo、無關歷史或秘密；但不可省略完成條件、失敗案例、負向對照或會改變判斷的限制。
- 背景改變時記錄受影響判斷與 step；不同版本不得直接比較或互相覆寫結論。

所有狀態與結論遵守技能中的「證據不變量」：可觀察證據、來源、時間或版本三者缺一時，只能標示為未驗證或推論。
