# 執行、鎖與看門狗

Codex 全域設定 `features.goals = false`：新啟動的執行環境不以原生持續目標在回合結束後立即再開一輪。單輪內仍完成已授權工作；長命令使用既有程序等待介面，不能用反覆 `tail` 代替等待。此設定不停止已啟動的環境或背景程序，也不關閉 Claude Code 或 Orca 的獨立排程。

只有使用者明確要求跨回合自動續跑，才另外啟用該次原生目標。token 上限由使用者選擇是否設定；未指定時省略 token_budget，不自行猜數字（使用者 2026-10-26 修訂）；不得為繞過預設自行加 `--enable goals`。一般長任務、LOOP 或「繼續做」不等於授權無上限原生目標。原生目標的內部續跑不經 UserPromptSubmit；Stop 的 `continue:false` 只停止當前回合，不能當作跨回合停用機制。

LOOP 不是背景程序。只有持續任務才設喚醒；等人時停排程、不喚醒（使用者 2026-10-15 定）；等外部事件才排，間隔至少 20 分鐘，更密要記理由。長命令不因到點中斷。看門狗只檢視停滯、偏離、新阻塞與證據有效性，不重跑完整測試、不當外部連線重試器。

- 先查同目錄主 LOOP 是否已有 owner、排程、鎖；有就沿用。沒有排程權限就記「未啟動背景循環」，仍做前台工作，不用 shell `while` 迴圈替代。
- 跨喚醒寫共用狀態要有 lease：`task_id`、`owner_id`、`acquired_at`、`heartbeat_at`、`lease_until`、`lock_version`；每 lease／3 續租；到期只代表可能 stale，確認心跳過期且 owner 不存活並原子比對後才接手；確認不了轉 `WAITING`，不搶鎖、不開第二個寫入者。
- 喚醒時：讀 LOOP 與當前 step，核對證據與未完成驗收，只做最小必要動作；有人在做就留提醒退出。停止只影響本任務的排程。
