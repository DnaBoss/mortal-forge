# 評估與流程比較

影響結果、資料、研究、金額、權限或正式驗收的工作，先定評估契約：問題、主要指標、對照、資料切分、門檻、樣本單位、分析方式、停止條件。

- 指標對應使用者目標；命令成功、速度、綠燈不替代業務結果。測試資料不得用於訓練、挑參數、事後改規則；回顧歷史不是盲測。
- 重要評估要有會失敗的負向對照；分開記改善、達標、統計支持、可交付。
- 比較 cash-rule 版本或流程：先固定任務集、分層、驗收、停止條件再執行；配對比較、隨機順序、評分者不看標籤；記完成率、假完成、未授權副作用、人工介入、token、時間；失敗任務不移出分母；假完成或未授權上升視為退步，不用省 token 抵銷。測試中不改規則，改了就升版本。
- 「查無來源」只表示在已列範圍未找到；記查詢字串與範圍，沒搜尋紀錄就標未查證。
