# 架構與流程圖

使用者要的是從圖形空間與連線直接讀懂關係，不是把段落換成表格、文字列或箭頭清單。這是呈現偏好；不增加任務範圍、操作授權或外部發布權限。

## 選對圖

- 組件、部署位置、包含關係：系統架構圖。需要同時說明資料位置時，用「含資料流的系統架構圖」。
- 先後呼叫與回應：時序圖，參與者分欄，時間沿單一方向推進。
- 步驟、條件、重試、停止與回饋：流程圖，畫出分支及回到前一步的線。
- 數據比較才用圖表；純欄位對照可保留表格。使用者指定格式時優先遵守。
- 不必要求使用者說出圖的專有名詞；根據內容自行選擇。

## 圖上必須看得到的關係

1. 用有意義的位置、分組與巢狀框表達層級。框在裡面必須真的表示包含，不能只為好看而框在一起。
2. 用連接線及箭頭表達方向；把介面或傳遞內容標在線旁。需要說明回程時畫回程，不能只寫「沿原路回來」。
3. 程式控制、資料載入等不同類型的關係，使用不同線型及標籤；可搭配顏色與圖例，不能只靠顏色區分。
4. 程式、資料、硬體、儲存位置分開畫。不要把模型權重畫成會接 HTTP 的服務，也不要把程序內函式庫畫成另一個服務程序；其他領域遵循同樣的語意準確性。
5. 節點只放名稱及必要短句，說明與來源放圖外。文字框連成一列、每框塞一段原文，仍不符合這個偏好。
6. 關係太多時拆成總覽與局部圖；不要在單頁縮小到看不清楚。修改既有文件時，盤點所有相關頁，尤其使用者引用的那一頁，不能只改相鄰頁。

## 製作與驗收

- 聊天中的小型靜態圖，可用支援渲染的 Mermaid。PDF／簡報優先使用 SVG 或其他清晰的向量圖；需要互動才用互動視覺化。沿用交付格式的技能，不強迫換格式。
- 查證重要關係；對未知或示意配置明確標示，不為畫出完整圖而發明元件或接口。
- 實際查看最後交付的圖或 PDF 頁面，確認文字、箭頭、圖例、來源與頁尾沒有相撞、截斷；不能只以文字抽取或檔案生成成功作為驗收。
- 驗收問題：不讀長段說明，能否從圖上指出「誰包含誰、誰呼叫誰、傳什麼、資料在哪裡、下一步去哪裡」？只檢查本圖適用的關係。若仍必須逐段讀完文字才能理解，重畫。
- 交付說明指出改到哪些圖／頁與驗證範圍；不要宣稱新 session 或其他 AI 已實際測試，除非真的執行過。

## 直線版佈局（使用者 2026-10-26 認可，PDF 圖預設照此做）

使用者嫌路線圖「線繞來繞去、互相交叉」，要的是分區塊、分流程、直線一對一。
- 一條線只連相鄰兩塊；不繞過其他框、不交叉、不重疊、不轉折。要連到較遠的框，就把中間留空，讓直線穿過空格。
- 流程由左到右排列；往下的關係用垂直線，上下欄位一一對齊。
- 一個框要連多個對象時，把對象放進同一個群組框（虛線外框），線連到群組，不拆成多條。
- 回程用雙向箭頭加「請求／回應」標籤，不另畫回繞線。
- 做法：手寫 HTML（CSS grid ＋ 用 div 畫的直線箭頭），Chrome headless 輸出 PDF；每頁底色設實際白底，再以保留透明度的轉圖檢查。可直接改 [範例 HTML](references/straight-line-example.html)，成品見 [範例圖](references/straight-line-example.png)。
- 驗收：看輸出圖，確認線沒穿過框內文字、標籤沒被截斷、群組框沒被內容撐破。

## 每次出 3 個版本讓使用者選（使用者 2026-10-27 定）

使用者要的是「同一張圖給 2～3 種風格選」，不是只給一張。預設照此做，除非使用者指定單一風格。
- 先把內容寫成一份 JSON（範例 [variants-example.json](references/variants-example.json)）：方塊（col、row）、群組框、連線；全部放在格子上，所以線一定是直的。
- 執行 `python3 -I ~/.agents/skills/architecture-diagrams/scripts/variants.py 規格.json 輸出資料夾 [--pdf] [--drawio]`，一次得到三版：
  - clean：白底、藍灰線，預設的正式交付版。
  - sketch：暖色、手繪抖動，適合討論初稿。
  - blueprint：深藍底，適合簡報投影。
  - `--drawio`：同一份內容輸出可編輯的 draw.io 檔；只驗過檔案格式，未用 draw.io 開過。
- 腳本先做版面檢查，沒過就不輸出：方塊不重疊、線只能水平或垂直、線不穿過別的框、線不交叉不重疊、標籤放得下、方塊文字放得下。錯誤訊息直接說哪條線有問題，照訊息改規格。
- 交付時三張 PNG 都要看過，再請使用者選；選定後只保留那一版，PDF 用 `--pdf` 重出，並照 PDF 底色規則逐頁檢查透明度。
- 來源：位置檢查的想法借自 fireworks-tech-graph、多風格與手繪借自 diagram-design、可編輯檔借自 drawio-skill（三者皆 MIT）。沒有安裝它們；需要它們的 45 種圖型、十幾種風格或 GIF 動畫時，再另外下載使用。
- 偏好調整：顏色與線寬在 `variants.py` 的 `THEMES`，格子大小在檔案最上方常數。
