# 精簡實作：按需檢查

新增功能、依賴或抽象前，搜尋相同用途、呼叫端與已裝依賴。已有能力就直接使用；確需新抽象或套件，在既有任務紀錄留一句現有方式不足的原因，不另產報告。程式與註解的精簡原則沿用共用規約。

交付前檢視本次差異：未用程式、重複邏輯、只轉傳的包裝、假想設定、重述程式的註解。必要相容層與公開介面不因看似多餘而移除。小修改沿用既有檢查，不為套流程重跑全部工具。

## 可直接使用的工具

固定安裝位於 `~/.local/share/code-quality`，版本與完整依賴見該目錄 `package-lock.json`；不修改產品套件清單。先用專案已有版本與設定，沒有才用共用版本。下列參數不自動修檔。以 120 秒為單次上限，逾時縮小工作區；不反覆重跑同一範圍。

- JavaScript／TypeScript：Knip 6.42.0 找未用檔案、匯出與依賴。需從正確工作區和入口分析；不能只餵修改檔案，否則會漏掉使用者。首次結果人工確認動態載入、套件公開入口及框架慣例，不直接當刪除依據。

```sh
timeout 120 ~/.local/share/code-quality/node_modules/.bin/knip --directory /absolute/project --reporter json
```

- 多語言：jscpd 5.4.1 找複製區段。選修改模組及可能重用的相鄰來源，不只掃修改檔案，也不掃全部歷史。排除產物與第三方程式。輸出存工作區外，只讀與本次差異相關的發現；重複不必然該抽象，不要求零重複率。

```sh
timeout 120 ~/.local/share/code-quality/node_modules/.bin/jscpd /absolute/module /absolute/shared --mode weak --ignore '**/node_modules/**,**/target/**,**/dist/**,**/vendor/**' --reporters json --output /absolute/evidence
```

- Rust：沿用專案的 Clippy 與編譯警告；不重跑已通過的同版檢查，不新增另一套 Cargo 快取。

禁止為此啟用 Knip `--fix`／`--allow-remove-files`、jscpd 模型推論或下載模型；自訂設定可能執行專案程式，先確認來源。工具缺少設定或找不到入口時修正量測範圍，不能用忽略錯誤來宣稱通過。新套件升級需另驗，不自動追最新版。

## 成效與邊界

工具不能判定所有過度設計、註解必要性或需求完整度；由實作者對差異判斷，有高風險或明確疑點才另派審查。不要每個小修改都加一次模型審查。

預設直接生成短回答，檢查器只作防漏；完整程式與必要證據不以 150 字硬截。只報新結果、阻塞或重大決策，避免空泛進度。使用者要詳細才展開；不要另產 HTML、日誌長文代替精簡。

比較成效用相同模型、題目、上下文與驗收：分開記最終文字、全部輸出 token、輸入與快取、工具呼叫及重寫次數。不以字數代替 token，不以單次通過宣稱長期改善；原始用量缺失就標未量測。
