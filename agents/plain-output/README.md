# 全域白話輸出檢查

更新：2026-09-12。這一版有全域規則、回答後檢查，以及獨立的顯示前檢查入口。
它還不是覆蓋所有 AI 畫面的沙箱，也不是模型無法修改的管理員隔離。

## 已裝上

- Codex：全域 AGENTS.md，加上每次開場、收到訊息、回答結束時的檢查。
- Claude Code：全域 CLAUDE.md、asd-ste100 風格，以及同樣三個時機的檢查。
- 共用規則：POLICY.md。檢查程式：guard.cjs。
- 目前程式檢查五組已登記的陌生用語是否附有同句說明，保留學習曲線等常用詞。
  未登記的陌生詞、整體可讀性、所有繁簡體差異尚不能自動判定。
- 回答後檢查要求一次重寫，仍不合格就停止並標明失敗，不無限呼叫模型。
  這個檢查不能收回已經顯示的文字。

## 檢查通過才顯示的入口

```sh
plain-ai codex "請解釋學習曲線"
plain-ai claude "請解釋學習曲線"
```

這是問答用入口。Codex 採唯讀環境，Claude 不提供工具，不能取代原本的程式開發工作階段。
它只啟動一次模型程序，先收齊完整回答，再交給檢查程式。中間進度與工具輸出不直接顯示。
不合格、模型失敗、內容不完整、解析錯誤或逾時時，輸出簡短錯誤並結束，不放行原回答。
原來的 codex／claude 指令、Orca 畫面沒有被替換，仍可繞過此入口。

## 還缺什麼才是全程強制

1. Orca 及其他使用中的畫面，必須在訊息顯示前一律經過檢查，包含進度與最終回答。
2. 檢查失敗或檢查服務不可用時不能顯示原文；要有畫面層測試證明。
3. 規則與檢查程序由獨立帳號或管理員管理，模型不能自行修改；目前同帳號檔案尚無此隔離。
4. 擴充可讀性判定要有獨立測試；不能把五組詞表說成完整白話理解。

下一步要接實際聊天介面的程式。單改全域 Markdown 或回答結束時的設定，不能完成顯示前隔離。
目前不宣稱「所有 AI 每次都已強制通過」。
